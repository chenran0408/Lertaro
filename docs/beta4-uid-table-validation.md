# Beta 4 验证记录

## 改动

压缩索引时沿用快照已有的名称 UID 表。未改变的行直接复用整数 UID，不再对每一行重复做名称字典查找；只有新增或改名的名称才分配新的 UID。

## 结果

在同一台 Windows x64 机器上，使用 200,000 行 ASCII 合成索引、10 次压缩，分别运行修改前 `55326ad8` 和修改后版本：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 进程托管分配量 | 549,128,576 B | 437,102,328 B |
| 压缩中位数 | 73.77 ms | 76.70 ms |
| 最终行数 | 200,010 | 200,010 |

托管分配量下降约 20.4%。压缩耗时在该次运行中没有稳定下降，因此本轮只记录内存收益，不宣称整体压缩速度提升。搜索结果和最终行数保持一致。
