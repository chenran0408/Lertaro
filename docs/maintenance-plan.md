# 后续维护顺序

每次只推进一个可独立验收的改动，完成构建、相关回归与发布前检查后，发布 GitHub Beta 预发布和 x64 安装包，再开始下一项。发行说明只描述实际完成的效果与已知限制。

1. **Beta16：移除废弃玻璃流程与构建残留。** 清理已无作用的显示准备分支、空回调、旧渲染测试依赖和打包步骤；保留普通主题、自定义背景及搜索展开修复。验收弹窗关闭、搜索展开与背景图。
2. **Beta17：搜索中间数据与路径分配优化。** 分块消费匹配结果并直接生成路径；完成受控索引对照与 148 项定向测试。实际收益和完整搜索略慢的限制见 `beta17-memory-validation.md`。不用强制清空工作集代替内存优化；App 原生渲染常驻占用仍待后续处理。
3. **Beta18：修复过期焦点回调。** 快速隐藏并重开搜索窗后，旧请求不再覆盖新查询的光标位置；真实 WPF 复现和 7 项焦点测试通过，见 `beta18-focus-validation.md`。后续继续按实际复现检查键盘操作与窗口反馈。
4. **Beta19：动作菜单输入法修复。** 拼音首字母不再被当作菜单助记键执行动作，普通字母及组合快捷键保留；定向测试与真实 IME 测试窗口验证见 `beta19-ime-validation.md`。
5. **Beta20：恢复索引状态反馈。** 显示已有加载、索引进度和就绪状态；窄窗口长文字自动省略。真实控件和搜索窗口布局验证见 `beta20-status-validation.md`。

后续继续按“一个问题、一次验证、一个 Beta”的方式排队。保留用户设置及索引；视觉以已确认移除玻璃后的普通浅色／深色界面为准，不恢复玻璃效果。

本轮 Beta17–20 汇总为 5.10.2 正式版，发行前执行覆盖安装与启动／搜索集成检查。后续新一轮 Beta 使用 5.10.3 作为版本基数；原生渲染常驻占用和完整搜索耗时仍有后续优化空间，不将本轮局部收益宣称为全部性能目标完成。
