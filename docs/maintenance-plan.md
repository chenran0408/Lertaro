# 后续维护顺序

每次只推进一个可独立验收的改动，完成构建、相关回归与发布前检查后，发布 GitHub Beta 预发布和 x64 安装包，再开始下一项。发行说明只描述实际完成的效果与已知限制。

1. **Beta16：移除废弃玻璃流程与构建残留。** 清理已无作用的显示准备分支、空回调、旧渲染测试依赖和打包步骤；保留普通主题、自定义背景及搜索展开修复。验收弹窗关闭、搜索展开与背景图。
2. **Beta17：搜索中间数据与路径分配优化。** 分块消费匹配结果并直接生成路径；完成受控索引对照与 148 项定向测试。实际收益和完整搜索略慢的限制见 `beta17-memory-validation.md`。不用强制清空工作集代替内存优化；App 原生渲染常驻占用仍待后续处理。
3. **交互体验第一项：按复现证据选择一个问题。** 检查快速搜索、快速面板与设置的键盘焦点、Esc/Enter、窗口关闭重开和结果反馈；选择一个确认存在的问题修复，验证后单独发布 Beta。

后续继续按“一个问题、一次验证、一个 Beta”的方式排队。保留用户设置及索引；视觉以已确认移除玻璃后的普通浅色／深色界面为准，不恢复玻璃效果。
