# Lertaro 6.3

- The clipboard panel now has its own shortcut, set to Win+V by default, so you can open it just like the system clipboard history.
- You can change this shortcut any time in Settings > Hotkeys.
- The Anime Themes and Curated Themes plugins are back in Appearance > Interface Theme, after going missing in an earlier release.
- Clipboard search is faster for longer text, and routine fixes under the hood.

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
