# Lertaro 6.7.4

- 快速搜索同时查找应用和文件，连续输入时会停止旧查询。用几个词找文件时，优先检查最可能排进首页的结果。
- 搜索框唤出即可阅读，按 Esc 立即收起。方向键移动时选中行立即高亮，快捷启动来源直接显示名称。
- 剪贴板可用 Alt+V 唤出，支持滚轮选择和单击粘贴。插件设置有独立入口，网页搜索可添加哔哩哔哩等常用网站。
- 收藏夹和快捷启动改名后可直接应用，筛选后清理只影响匹配项。局域网群发可以只重试失败设备。

普通 Windows 电脑下载 **Lertaro-Setup.exe** 覆盖安装；ARM 电脑选择 **Lertaro-Setup-arm64.exe**。免安装使用请选择对应的 Portable 压缩包。
