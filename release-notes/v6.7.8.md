## 搜索与文件操作

- 只搜文件或文件夹时，同名项目再多也更容易找到目标。重复搜索同一个词时可以更快看到结果，长中文文件名也能用拼音首字母查找。
- 搜索会识别 Windows 实际使用的桌面。浏览结果时，仅联机的快捷方式不会因为取图标被下载。
- Windows 右键子菜单加载时仍可返回或关闭。重新打开快速启动时，已有图标会保留到新图标就绪。
- 在文件窗口里完成内联搜索后可以接着操作。内容搜索在切换筛选或关闭窗口后会正确更新。
- 新增 Tessoa 和 xplorer² 文件管理器适配。日历更新节假日数据，并可在插件设置中开启提醒音效。

**下载**　普通 Windows 电脑选择 `Lertaro-Setup.exe`，ARM 电脑选择 `Lertaro-Setup-arm64.exe`。需要免安装时，下载对应的 Portable 压缩包。
