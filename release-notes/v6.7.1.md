# Lertaro 6.7.1

## 搜索更聪明

- 四个过滤关键词：在关键词后面加 `folder:目录`、`file:`、`ext:pdf,docx`、`datemodified:today`（或 thisweek / 年-月），边搜边筛。
- 结果列表顶部新增快捷筛选条：全部 / 文件夹 / 文件 / 图片 / 文档 / 本周，一键切换。
- 打开过的文件会「越用越靠前」——使用频率高的文件自动上浮。
- 隐藏文件与系统文件默认不出现在搜索结果，设置→通用→系统可开启。

## 剪贴板面板全面升级

- 修复列表行不显示内容预览的问题：此前每行只显示来源和时间，看不到复制的是什么。
- 行内新增类别图标栏（文本/文件/图片一目了然）和内容两行预览，更大的图片缩略图。
- 前九条显示快捷粘贴槽位徽章，按对应数字键即可直接粘贴。
- 鼠标悬停即可看到条目的完整内容，不必打开预览。
- 鼠标点击行的任意位置（包括空白处）都能选中；双击粘贴；右键菜单一切如常。
- 点击面板以外的区域，面板自动收起。
- 每条记录可以添加备注：选中后在预览底部直接输入，备注参与搜索。
- 「最多使用」排序现在统计粘贴次数，真正常用的记录会浮上来。
- 面板会记住上次的标签页、排序方向和预览窗格宽度。
- 点击面板外自动收起；Esc 先清空搜索再关闭面板。

## 系统集成

- 任务栏右键 JumpList：最近搜索 + 收藏目录，点击直达。
- `lertaro://search?q=` 协议支持参数化查询。
- Windows 服务崩溃后 60 秒自动重启。
- 卸载时可选择是否保留用户数据。
- Web 关键词搜索：输入 `g 关键词` 进入 Web 搜索（关键词可编辑；联想默认关闭）。

## 隐私

- 隐身查询前缀 `;`：以分号开头的搜索不会被记录到历史。
- 设置→历史页新增「退出时清空搜索历史」开关（默认关）。

## 使用引导全新改版

- 引导不再只是看：每一步都是真实操作——按热键真的唤起搜索、输入真的出结果，做对了自动进入下一步。
- 键帽动画演示每一步的按键；搜索窗弹出时引导卡自动停靠在搜索窗旁边，关闭后自动回到原位——引导全程完整可见，不再折叠收起。
- 首次启动自动出现；之后可通过托盘菜单或「设置→关于→使用引导」随时回看。

## 修复

- 修复首次启动引导弹出时的程序异常。
- 修复点击搜索框图标时托盘菜单崩溃的问题。
- 修复快速搜索窗口 Esc 直接关窗的问题：现在先清空搜索，再按才关闭。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
