# Lertaro 6.1 Beta 1

- Search remains available while the background index is prepared for saving.
- A failed index save keeps pending file changes so it can be retried without losing search updates.
- Release packages must pass installation and update checks before they are published.

This is a test version. Existing installations can be updated with the matching installer.
For most PCs choose Lertaro-Setup.exe; ARM PCs should choose Lertaro-Setup-arm64.exe.
