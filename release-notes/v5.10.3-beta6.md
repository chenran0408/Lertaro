# Lertaro v5.10.3-beta6

This beta makes large index rebuilds faster and keeps search and update behavior from the previous beta.

- Faster sorting when rebuilding a large file index.
- No change to search results or file ordering.
- Available as Windows x64 and ARM64 installers and portable packages.

Download the package matching your computer. Existing users can install it over the current Lertaro installation.
