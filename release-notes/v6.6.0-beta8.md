# Lertaro 6.6.0-beta8

## 搜索更聪明（借鉴 Listary）

- 四个过滤关键词：`folder:目录`、`file:`、`ext:pdf,docx`、`datemodified:today/thisweek/2026-11`——边搜边筛。
- 结果列表顶部新增快捷筛选条：全部/文件夹/文件/图片/文档/本周。
- 打开过的文件会越用越靠前（使用频率排序）。
- 隐藏文件默认不显示，设置→通用→系统可开启。
- Web 关键词：输入 g 测试词 进入 Web 搜索模式（可编辑关键词列表；联想默认关闭）。

## 系统集成更好

- 任务栏右键 JumpList：最近搜索 + 收藏目录，点击直达。
- `lertaro://search?q=` 协议支持参数化查询。
- Windows 服务崩溃后 60 秒自动重启。
- 卸载时可选择是否保留用户数据。

## 隐私

- 隐身查询前缀 `;`：以分号开头的搜索不会被记录到历史。
- 设置→历史页新增「退出时清空搜索历史」开关（默认关）。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
