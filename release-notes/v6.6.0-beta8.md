# Lertaro 6.6.0-beta8

## 搜索更强（借鉴 Listary）

- 四个过滤关键词：`folder:目录`（限定目录）、`file:`（只看文件）、`ext:pdf,docx`（限定扩展名）、`datemodified:today/thisweek/2026-11`（按时间）。边搜索边过滤，结果计数即时准确。
- 结果列表顶部新增快捷筛选条：全部 / 文件夹 / 文件 / 图片 / 文档 / 本周，一键切换，与过滤词同一后端。
- 打开过的文件会「越用越靠前」：同分结果里，高频文件自动上浮。
- 隐藏文件与系统文件默认不出现在搜索结果，设置→通用→系统里可开启显示。
- Web 关键词：输入 `g 测试词`（或 b/w）进入 Web 搜索，回车打开浏览器；关键词列表可在设置中编辑。联想功能默认关闭——开启会把输入内容发送给搜索引擎，设置里有说明。

## 文件对话框与新手引导

- 打开/保存对话框上方会浮现「建议文件夹」条，点击直接跳转到刚用过的文件夹（每个对话框只出现一次；Ctrl+G 热键不变；设置里可关闭）。
- 引导升级：索引构建中会自动改教「等待索引」；热键被占用时自动改教托盘唤起；多显示器/DPI 定位更准。
- 新增三张「小提示」卡片：第一次用文件对话框、第一次打开剪贴板面板、第一次搜索无结果时各出现一次，均可关闭不再打扰。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
