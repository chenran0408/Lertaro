# Lertaro 6.6.0-beta3

## 首启引导全新改版

- 引导不再只是看：每一步都是**真实操作**——按热键真的唤起搜索、输入真的出结果、回车真的打开文件，做对了自动进入下一步。
- 键帽动画演示每一步的按键；搜索窗弹出时引导自动收拢让位，关掉搜索窗它再回来。
- 30 秒没操作会折叠成角落小条，点击随时继续；Esc 可随时跳过。
- 新装用户自动看到；老用户会收到一次新版引导（之后只在你想看时出现：托盘菜单或「设置 → 关于 → 使用引导」）。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
