# Lertaro v6.0.0

Lertaro 6.0 makes large index updates faster and lighter while keeping search results unchanged.

- Large indexes use less temporary memory when they are saved or updated.
- Search starts faster on smaller indexes and remains responsive on large indexes.
- Automatic updates are more reliable, including silent updates for standard users.
- The first-install black window issue is fixed.
- You can start an update from the app without opening the project page in a browser.

Existing users can install the matching package over the current Lertaro installation. Portable users can replace their existing portable folder after closing Lertaro.
