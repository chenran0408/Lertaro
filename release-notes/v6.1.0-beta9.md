# Lertaro 6.1 Beta 9

- The search title bar now has a one-click button to clear all active filters.
- Clearing several filter groups at once refreshes the results only once.
- Filter status remains visible when the filter panel is collapsed.

这是测试版本。普通电脑选择 `Lertaro-Setup.exe`，ARM 电脑选择 `Lertaro-Setup-arm64.exe`。
