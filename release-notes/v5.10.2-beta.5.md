# Lertaro 5.10.2 Beta 5

- Hidden glass windows release image resources while they are not in use, reducing idle memory use.
- Reopening a glass window prepares its current background again. If preparation takes longer, the window opens and continues updating.
- Keeps the faster search response and full plugin set from Beta 4.

Install `Lertaro-Setup.exe` on x64 Windows or `Lertaro-Setup-arm64.exe` on ARM64 Windows. Portable builds are also available.
