# Lertaro 6.6.0-beta4

## 修复

- 修复首次启动引导弹出时的程序异常：引导窗不再向尚未显示的主窗口登记归属，首次弹出改为屏幕居中（引导的时机与内容不变）。
- 修复点击搜索框图标时托盘菜单崩溃的问题：菜单里缺失的「使用引导」项现在会正确创建。
- 修复剪贴板面板鼠标点击无效的问题：现在点击行的任意位置（包括空白处）都能选中，悬停有反馈，双击粘贴、右键菜单、滚轮滚动一切如常。
- 剪贴板面板新增失焦自动收起：点击其他窗口时面板自动关闭（Esc、再按 Win+V 也照常关闭），与主流剪贴板工具一致。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
