# Lertaro 6.4.0

剪贴板功能全面升级，向专业剪贴板工具看齐，并完成一轮工程清理。

## 剪贴板面板

- 全新专属面板（Win+V 打开，再按一次关闭）：支持按 文本 / 图片 / 文件 / 收藏 分类筛选，按日期分组显示，面板在鼠标位置弹出。
- 新支持记录和粘贴图片与复制的文件；图片直接显示缩略图，选中即可在预览窗格查看大图或全文。
- 富文本保留格式：从网页或 Office 复制的内容粘贴后保持原有排版；Ctrl+Enter 按纯文本粘贴。
- 面板内搜索支持拼音与模糊匹配，命中内容高亮显示。
- 数字键 1~9 一键粘贴前九条；Del 删除，Ctrl+P 置顶，右键菜单集中全部操作。
- 支持从面板直接拖拽：文字、文件、图片（自动落盘 PNG）都能拖到聊天窗口、资源管理器等任意目标。
- 多选合并粘贴：按住 Ctrl 选多条，文字自动拼接、文件路径自动去重合并。
- 置顶收藏：置顶条目始终在前，不会被自动清理，粘贴后面板保持打开方便连续粘贴。
- 按钮式"暂停采集 10 分钟"，无需进设置；来源窗口一键跳回。
- 新增"历史保留时长"设置（1 / 7 / 30 天或永久），过期记录自动清理；支持从其他应用粘贴文件路径的三种格式（原样 / 带引号 / WSL）。

## 其他

- 移除未使用的内置组件，减小安装体积。
- 官网文档新增剪贴板历史使用指南（七种语言）。

提示：如果按下 Win+V 没有反应，多半是系统自带的剪贴板历史占用了这个键。到 Lertaro 设置中打开"打开 Windows 剪贴板设置"，关闭系统功能即可。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
