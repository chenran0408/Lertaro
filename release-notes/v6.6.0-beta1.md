# Lertaro 6.6.0-beta1

## 全新外观

- 全部窗口在 Windows 11 上拥有真正的系统圆角，与系统视觉保持一致（Windows 10 保持方角，不影响使用）。
- 使用键盘操作时，按钮、列表、复选框等控件会显示清晰的聚焦光环，键盘导航一目了然；鼠标操作不受影响。
- 弹出菜单和浮层获得统一细描边与柔和投影，层次更清晰。
- Windows 11 电脑默认使用新代 Segoe UI Variable 字体，等宽场景改用 Cascadia Mono；旧系统自动回退原字体。
- 设置按钮补上按下反馈；搜索、空隙、圆角等细节在全应用范围内统一。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
