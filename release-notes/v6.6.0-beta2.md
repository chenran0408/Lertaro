# Lertaro 6.6.0-beta2

## 全局快捷粘贴（新）

- 不打开面板，直接粘贴：按 `Ctrl+Win+1` 到 `Ctrl+Win+9`，把剪贴板历史里第 N 条直接粘贴到当前窗口（设置里可关闭）。

## 历史随身带（新）

- 右键菜单新增「导出历史…」/「导入历史…」：一个 ZIP 文件装下全部历史（含备注、置顶和图片），换机或重装不再丢数据。

## 图片独立保留时长（新）

- 截图与图片现在有单独的保留期限（默认 14 天，可设 1/7/14/30 天或永久），文本与文件仍按原设置保留，磁盘不再被旧截图悄悄占满。

## 界面打磨

- 历史列表行重做：类别图标栏（文本/文件/图片一目了然）、内容两行预览、更大的图片缩略图、更舒适的字号与间距。
- 行悬停即可看完整内容；前九条显示快捷粘贴槽位徽章；Home / End 跳转首尾。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
