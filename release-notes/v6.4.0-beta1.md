# Lertaro 6.4.0-beta1

剪贴板面板全面翻新，向专业剪贴板工具看齐：

- 全新专属面板（Win+V 打开）：支持按 文本 / 图片 / 文件 / 收藏 分类筛选，按日期分组显示。
- 新支持记录和粘贴图片与复制的文件，图片在面板中直接显示缩略图。
- 面板内搜索支持拼音和模糊匹配；可以置顶收藏，置顶条目始终在前且不会被自动清理。
- 选中多条记录（按住 Ctrl 点击）可合并成一条粘贴：文字自动拼接，文件路径自动去重合并。
- 数字键 1~9 一键粘贴前九条；Enter 直接粘贴，Ctrl+Enter 按纯文本粘贴，Del 删除，Ctrl+P 置顶。
- 新增"历史保留时长"设置（1 / 7 / 30 天或永久），过期记录自动清理。
- 面板在鼠标位置弹出，粘贴自动送回你之前的窗口；复制来源信息更准确。

提示：如果按下 Win+V 没有反应，多半是系统自带的剪贴板历史占用了这个键。到 Lertaro 设置中打开"打开 Windows 剪贴板设置"，关闭系统功能即可。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
