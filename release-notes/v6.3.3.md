# Lertaro 6.3.3

- Pinned clipboard entries no longer close the panel when pasted, so you can paste the same snippet again and again: Win+V, click, Win+V, click.
- Unpasted entries behave as before: pasting one closes the panel and returns focus to your window.

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
