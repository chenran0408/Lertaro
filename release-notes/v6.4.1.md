# Lertaro 6.4.1

## 更新体验重做

- 更新不再在后台悄悄替换文件：点击「下载更新」后，安装包保存到你的下载文件夹，完成后会引导你手动运行安装程序，全程你说了算。
- 更新完成后，关于页会显示「已从旧版本更新到新版本」，结果一目了然。
- 发现新版本的弹窗上新增「不再自动提示更新」勾选：勾选后彻底安静，不再检查、不再弹框；关于页的「检查更新」按钮随时可用，开关也可在关于页重新打开。

## 剪贴板面板

- 时间显示改为「刚刚 / 5 分钟前 / 3 小时前」等相对格式，一眼看出哪条是刚复制的。
- 文本和文件条目不再显示空的缩略图占位框，列表更紧凑；行距微调，阅读更舒适。

## 清理

- 自动清理历史版本遗留的更新残留文件（update-payload、update.lock 等）。

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
