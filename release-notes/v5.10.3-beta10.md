# Lertaro v5.10.3-beta10

This beta improves automatic updates for standard Windows users.

- Automatic silent updates no longer require the Lertaro window to run as administrator.
- Updates still use the installed background service and package signature checks.
- Manual update from the About page remains available without opening the project page in a browser.

Download the package matching your computer. Existing users can install it over the current Lertaro installation.
