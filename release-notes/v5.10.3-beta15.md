# Lertaro v5.10.3-beta15

This beta makes large index saves use less temporary memory.

- Snapshot writing now reserves the space it already knows it needs before writing names and indexes.
- Large saves allocate less memory while keeping the same index file and search behavior.
- Existing update and search behavior is unchanged.

Download the package matching your computer. Existing users can install it over the current Lertaro installation.
