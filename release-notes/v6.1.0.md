# Lertaro 6.1

- Search filters can be collapsed when you want more room for results.
- Active filters remain visible while the filter panel is collapsed.
- One click clears all active filters and refreshes the results once.
- Updates can be checked and installed from the About page without opening GitHub or requiring administrator rights.
- Silent updates report failures clearly and keep the app from getting stuck in a restart loop.
- Windows x64 and ARM64 installers and portable packages are available.

普通电脑选择 `Lertaro-Setup.exe`；ARM 电脑选择 `Lertaro-Setup-arm64.exe`。也可以下载对应的免安装版 ZIP。
