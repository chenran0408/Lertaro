- 用中文、拼音或程序缩写搜索时，更容易找到想启动的应用。快捷方式与程序同时命中时，会优先显示能认出的名称。
- 插件设置按用途分类。网页搜索可以添加哔哩哔哩、知乎、豆瓣和京东。插件详情支持点开说明，配置列表的添加按钮也更好找。
- 局域网传输把接收选项与网络设置分开，服务日志有了独立的筛选栏。日历可用 Page Up 和 Page Down 翻月，Flow 插件支持全角空格。
- 无痕搜索也能直接显示翻译完成后的结果。正文索引维护时会保留其他功能正在使用的数据库连接。
- 快速面板支持用方向键编辑筛选词。剪贴板默认用 Alt+V 打开，可滚轮选择、单击粘贴。

普通 Windows 电脑下载 **Lertaro-Setup.exe**。需要免安装时选择 **Lertaro-Portable.zip**。ARM 电脑请选择带 **arm64** 的对应文件。
