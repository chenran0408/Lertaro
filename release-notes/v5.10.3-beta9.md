# Lertaro v5.10.3-beta9

This beta makes full index saves use less temporary memory and finish more smoothly on large indexes.

- Reduces duplicate data created while rebuilding an index.
- Keeps the existing snapshot format and search results compatible.
- Includes the faster incremental compaction and alias reuse from the previous beta.

Download the package matching your computer. Existing users can install it over the current Lertaro installation.
