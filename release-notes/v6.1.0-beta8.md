# Lertaro 6.1 Beta 8

- The filter button now shows a small indicator whenever search filters are active.
- The indicator remains visible after the filter panel is hidden, so filtered results are never ambiguous.
- Existing filters and the `Ctrl+Shift+F` shortcut continue to work as before.

这是测试版本。普通电脑选择 `Lertaro-Setup.exe`，ARM 电脑选择 `Lertaro-Setup-arm64.exe`。
