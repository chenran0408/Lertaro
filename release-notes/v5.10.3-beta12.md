# Lertaro v5.10.3-beta12

This beta makes automatic updates retry more reliably after a temporary problem.

- A failed download, signature check, or service connection no longer blocks the same update for 24 hours.
- The retry pause is recorded only after the updater has actually started, protecting against repeated failed installations.
- Manual updates and existing update safety checks are unchanged.

Download the package matching your computer. Existing users can install it over the current Lertaro installation.
