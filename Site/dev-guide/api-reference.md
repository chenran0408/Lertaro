# API Reference

The complete `Lertaro.PluginSdk` surface is documented in an autogenerated reference: <a href="/api/index.html">PluginSdk API Reference</a>. It is generated by DocFX directly from the current SDK source code, so every interface, class and service shown there — along with its signatures and XML comments — is read mechanically from the source. That includes `remarks` blocks, parameter and return descriptions, and cross-links between related types. The source comments are written in English and are preserved as-is in every language of this manual.

Because the reference is only as complete as the comments in the source itself, omissions may exist: a member with sparse or missing XML documentation is still listed, but not fully described. Treat the generated pages as a faithful map of the current code, not a guarantee that every behavior is documented.

For usage-oriented guidance — how to implement the interfaces, what the host does with the results, and which patterns are recommended — read the hand-written [Plugin SDK guide](./sdk/core-search-actions) and the pages that follow. The autogenerated reference supplements that guide rather than replacing it, and it is generated from the current build source, which may differ from the `Lertaro.PluginSdk` version shipped in an installed release.
