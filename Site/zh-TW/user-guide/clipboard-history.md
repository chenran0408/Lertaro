# 剪貼簿歷史

剪貼簿歷史外掛記錄你在這台電腦上複製的內容，並可搜尋、重新貼上。所有資料都保存在本機。

## 開啟面板

按 `Win+V`（可在 設定 → 熱鍵 中修改），或在搜尋框輸入觸發詞 `cb` 後選擇**開啟剪貼簿面板**。面板會出現在滑鼠位置。

如果按 `Win+V` 沒有反應，多半是系統內建的剪貼簿歷史佔用了這個按鍵：開啟 **設定 → 外掛 → 剪貼簿歷史 → 設定**，點擊**開啟 Windows 剪貼簿設定**關閉系統功能即可。

## 會記錄什麼

- 複製的**文字**（不超過設定的最大長度）。
- 複製的**圖片**（截圖、網頁圖片），面板中顯示縮圖。
- 在檔案總管中複製的**檔案和資料夾**。

密碼管理器在前台時發生的複製不會被記錄。預設排除清單包含 Keepass、KeepassXC、1Password、Bitwarden 和 Enpass，可在設定中追加。

## 面板操作

- 直接輸入即可過濾清單，支援與主搜尋一致的拼音和模糊匹配。
- 頂部分類標籤按類型過濾；收藏標籤只顯示釘選項目。
- 清單按分組顯示：釘選在最前，然後是今天、昨天和更早的日期。
- `Enter` 貼上選中項到你之前使用的視窗；`Ctrl+Enter` 按純文字貼上；`1`–`9` 直接貼上前九條；`Del` 刪除；`Ctrl+P` 釘選/取消釘選；`Esc` 關閉面板。
- 按住 `Ctrl` 或 `Shift` 點擊可多選，貼上時自動合併：文字按順序拼接，檔案路徑去重合併。
- 釘選項目貼上後面板保持開啟，方便反覆貼上常用內容。

## 設定

- **記錄剪貼簿歷史**：開關採集；已有歷史會保留。
- **歷史保留時長**：1 / 7 / 30 天或永久，過期未釘選項目自動清理，釘選不受影響。
- **最大條數**：未釘選項目的上限。
- **最大文字長度**：單條文字保存的字元數。
- **排除的應用**：行程名，逗號分隔。

歷史資料保存在本機使用者資料目錄中；清空歷史會同時刪除已保存的圖片。
