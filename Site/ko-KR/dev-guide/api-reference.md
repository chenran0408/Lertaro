# API 참조

`Lertaro.PluginSdk`의 전체 API는 자동 생성된 참조 문서(<a href="/api/index.html">PluginSdk API 참조</a>)에서 확인할 수 있습니다. 이 문서는 DocFX가 현재 SDK 소스 코드에서 직접 생성한 것으로, 나열된 모든 인터페이스·클래스·서비스와 그 시그니처·XML 주석이 소스에서 그대로 읽힙니다. `remarks` 블록, 매개변수와 반환 값 설명, 관련 타입 간 교차 링크도 포함됩니다. 소스 주석은 영어로 작성되어 있으며 이 매뉴얼의 모든 언어에서 그대로 표시됩니다.

참조 문서의 완전도는 소스 주석 자체에 달려 있으므로 누락이 있을 수 있습니다. XML 문서가 드물거나 없는 멤버도 목록에는 나타나지만 완전히 설명되지는 않습니다. 생성된 페이지는 현재 코드의 충실한 지도로 취급하되, 모든 동작이 문서화되었다는 보장으로 삼지 마십시오.

인터페이스 구현 방법, 호스트가 결과를 처리하는 방식, 권장 패턴 등 사용법 안내는 손으로 작성한 [플러그인 SDK 가이드](./sdk/core-search-actions)와 이후 페이지를 읽으십시오. 자동 생성 참조는 그 가이드를 보완할 뿐 대체하지 않으며, 현재 빌드 소스에서 생성되므로 설치된 릴리스에 포함된 `Lertaro.PluginSdk` 버전과 다를 수 있습니다.
