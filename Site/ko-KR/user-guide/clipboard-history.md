# 클립보드 기록

클립보드 기록 플러그인은 이 컴퓨터에서 복사한 내용을 기록하고, 검색하여 다시 붙여넣을 수 있게 합니다. 모든 데이터는 로컬에 저장됩니다.

## 패널 열기

`Win+V`(설정 → 단축키에서 변경 가능)를 누르거나 검색 상자에 트리거 단어 `cb`를 입력한 뒤 **클립보드 패널 열기**를 선택하세요. 패널은 마우스 위치에 열립니다.

`Win+V`가 반응하지 않으면 Windows 기본 클립보드 기록이 이 키를 점유하고 있는 것입니다. **설정 → 플러그인 → 클립보드 기록 → 구성**에서 **Windows 클립보드 설정 열기**를 눌러 시스템 기능을 끄세요.

## 기록되는 항목

- 복사한 **텍스트**(설정한 최대 길이까지).
- 복사한 **이미지**(스크린샷, 웹 이미지). 패널에 썸네일로 표시.
- 파일 탐색기에서 복사한 **파일과 폴더**.

비밀번호 관리자가 전면에 있는 동안의 복사는 기록되지 않습니다. 기본 제외 목록은 Keepass, KeepassXC, 1Password, Bitwarden, Enpass를 포함하며 설정에서 추가할 수 있습니다.

## 패널 사용법

- 입력하는 즉시 목록이 좁혀집니다. 메인 검색과 같은 퍼지·한글/拼音 매칭을 지원합니다.
- 상단 탭으로 종류별로 필터링하고, 즐겨찾기 탭은 고정 항목만 표시합니다.
- 목록은 그룹으로 표시: 고정 항목이 맨 앞, 이어서 오늘·어제·이전 날짜.
- `Enter`로 선택 항목을 이전 창에 붙여넣고, `Ctrl+Enter`는 텍스트로 붙여넣기, `1`–`9`는 상위 9개 즉시 붙여넣기, `Del` 삭제, `Ctrl+P` 고정, `Esc` 닫기.
- `Ctrl`+클릭이나 `Shift`+클릭으로 여러 항목을 선택해 붙여넣으면 자동 병합: 텍스트는 줄바꿈으로 연결, 파일 경로는 중복 제거 후 통합.
- 고정된 항목은 붙여넣은 후에도 패널이 열려 있어 자주 쓰는 내용을 반복해서 붙여넣을 수 있습니다.

## 설정

- **클립보드 기록 저장**: 기록 켜기/끄기. 기존 기록은 유지됩니다.
- **기록 보관 기간**: 1 / 7 / 30일 또는 영구. 기한이 지난 고정되지 않은 항목은 자동 삭제, 고정 항목은 제외.
- **최대 항목 수**: 고정되지 않은 항목의 상한.
- **최대 텍스트 길이**: 항목 하나에 저장할 문자 수.
- **제외할 앱**: 프로세스 이름을 쉼표로 구분.

기록은 로컬 사용자 데이터 디렉터리에 저장됩니다. 기록을 지우면 저장된 이미지도 함께 삭제됩니다.
