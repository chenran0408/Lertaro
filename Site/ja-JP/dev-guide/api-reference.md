# API リファレンス

`Lertaro.PluginSdk` の完全な API は、自動生成されたリファレンス(<a href="/api/index.html">PluginSdk API リファレンス</a>)で確認できます。これは DocFX が現在の SDK ソースコードから直接生成したもので、記載されているすべてのインターフェイス・クラス・サービスとそのシグネチャや XML コメントは機械的にソースから読み取られています。`remarks` ブロック、引数と戻り値の説明、関連する型への相互リンクも含まれます。ソース中のコメントは英語で書かれており、このマニュアルのすべての言語でもそのまま表示されます。

リファレンスの完全さはソースコメントそのものに依存するため、欠落が存在する可能性があります。XML ドキュメントが少ない、または存在しないメンバーも一覧には現れますが、完全には説明されません。生成されたページは現在のコードの忠実な写像として扱い、すべての動作が文書化されている保証とはしないでください。

インターフェイスの実装方法、ホストが結果をどう扱うか、推奨パターンといった使い方の解説は、手書きの[プラグイン SDK ガイド](./sdk/core-search-actions)とそれに続くページを参照してください。自動生成リファレンスはそのガイドを補完するものであり、置き換えるものではありません。また、現在のビルドソースから生成されるため、インストール済みリリースに同梱される `Lertaro.PluginSdk` と異なる場合があります。
