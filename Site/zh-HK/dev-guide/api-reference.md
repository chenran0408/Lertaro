# API 參考

`Lertaro.PluginSdk` 的完整 API 由自動生成的參考文件承載：<a href="/api/index.html">PluginSdk API 參考</a>。該文件由 DocFX 直接從目前 SDK 原始碼生成，其中列出的每個介面、類別和服務——連同其簽章與 XML 註解——都機械地讀取自原始碼，包括 `remarks` 區塊、參數與回傳值說明以及相關類型之間的交叉連結。原始碼註解以英文撰寫，在本手冊的所有語言版本中原樣保留。

參考文件的完整程度取決於原始碼註解本身，因此可能存在缺漏：XML 文件稀少或缺失的成員仍會列出，但不會被完整描述。請把生成頁面視為對目前程式碼的忠實映射，而不是對「每個行為都已有文件」的保證。

關於如何實作介面、宿主如何處理結果以及推薦模式的用法指導，請閱讀手寫的[外掛模組 SDK 指南](./sdk/core-search-actions)及其後續頁面。自動生成的參考文件是對該指南的補充而非替代，且它生成自目前建置原始碼，可能與已安裝發行版附帶的 `Lertaro.PluginSdk` 版本不一致。
