# 剪贴板历史

剪贴板历史插件记录你在这台电脑上复制的内容，并可搜索、重新粘贴。所有数据都保存在本地。

## 打开面板

按 `Win+V`（可在 设置 → 热键 中修改），或在搜索框输入触发词 `cb` 后选择**打开剪贴板面板**。面板会出现在鼠标位置。

如果按 `Win+V` 没有反应，多半是系统自带的剪贴板历史占用了这个按键：打开 **设置 → 插件 → 剪贴板历史 → 配置**，点击**打开 Windows 剪贴板设置**关闭系统功能即可。

## 会记录什么

- 复制的**文本**（不超过设置的最大长度）。
- 复制的**图片**（截图、网页图片），面板中显示缩略图。
- 在资源管理器中复制的**文件和文件夹**。

密码管理器在前台时发生的复制不会被记录。默认排除列表包含 Keepass、KeepassXC、1Password、Bitwarden 和 Enpass，可在设置中追加。

## 面板操作

- 直接输入即可过滤列表，支持与主搜索一致的拼音和模糊匹配。
- 顶部分类标签按类型过滤；收藏标签只显示置顶条目。
- 列表按分组显示：置顶在最前，然后是今天、昨天和更早的日期。
- `Enter` 粘贴选中项到你之前使用的窗口；`Ctrl+Enter` 按纯文本粘贴；`1`–`9` 直接粘贴前九条；`Del` 删除；`Ctrl+P` 置顶/取消置顶；`Esc` 关闭面板。
- 按住 `Ctrl` 或 `Shift` 点击可多选，粘贴时自动合并：文字按顺序拼接，文件路径去重合并。
- 置顶条目粘贴后面板保持打开，方便反复粘贴常用内容。

## 设置

- **记录剪贴板历史**：开关采集；已有历史会保留。
- **历史保留时长**：1 / 7 / 30 天或永久，过期未置顶条目自动清理，置顶不受影响。
- **最大条数**：未置顶条目的上限。
- **最大文本长度**：单条文本保存的字符数。
- **排除的应用**：进程名，逗号分隔。

历史数据保存在本地用户数据目录中；清空历史会同时删除已保存的图片。
